# tuto-record — v0.3.0 Plan: Groups

v0.3.0 lets a Project hold **Groups**: containers of Tutorials and other Groups, nested as deep as needed. Tutorials and Groups can be moved by dragging them in the sidebar. Recording, the preview and the Settings window do not change.

- **Vocabulary:** Group is defined in [GLOSSARY.md](../GLOSSARY.md), next to Projects folder, Project and Tutorial.
- **Decisions:** [ADR 0003](../docs/adr/0003-groups-are-marked-with-a-hidden-file.md) (Groups are marked with a hidden file), which narrows [ADR 0002](../docs/adr/0002-folders-are-the-only-record.md).
- **Step-by-step build:** [V0.3.0_IMPLEMENTATION.md](V0.3.0_IMPLEMENTATION.md).
- **Previous version:** [V0.2.0_PLAN.md](V0.2.0_PLAN.md).

## 1. Decisions (from the design grill, 2026-11-21)

| #   | Topic             | Decision                                                                                                                                                                                                                                                                                       |
| --- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| G1  | Term              | **Group**. Avoid: section, chapter, folder, category                                                                                                                                                                                                                                           |
| G2  | Depth             | Unlimited. A Project and a Group can each hold Tutorials and Groups side by side                                                                                                                                                                                                               |
| G3  | Group or Tutorial | In order: contains `.tuto-group` → Group; contains an image → Tutorial (subfolders ignored); contains a visible subfolder → Group; otherwise → Tutorial ([ADR 0003](../docs/adr/0003-groups-are-marked-with-a-hidden-file.md)). Groups made in the app get the file. No migration of v0.2 data |
| G4  | Order             | At each level: Groups first, then Tutorials, each newest first by folder creation time                                                                                                                                                                                                         |
| G5  | Creating          | **+** on a Project or Group row opens a native menu: **New Tutorial** / **New Group**, then an inline name field as in v0.2. **+** next to PROJECTS still creates a Project directly                                                                                                           |
| G6  | Rename and delete | The ⋯ menu works for Groups as for Tutorials. Moving a Group to the Trash moves everything in it; the confirmation counts the Tutorials inside, at any depth                                                                                                                                   |
| G7  | Expanding         | Groups expand and collapse like Projects; expanded Projects and Groups are remembered                                                                                                                                                                                                          |
| G8  | Moving            | Drag a Tutorial or a Group onto any Project or Group row, in any Project. A Group moves with everything in it. A name already used at the destination is refused with a message. No confirmation: dragging back undoes it                                                                      |
| G9  | Drop rules        | Projects cannot be dragged. Tutorial rows are not drop targets. A Group cannot be dropped into itself or anything inside it. Dropping onto the current parent does nothing                                                                                                                     |
| G10 | Drag feedback     | The row under the pointer is highlighted when it accepts the drop; a collapsed Project or Group expands after the pointer rests on it for 0.6 s                                                                                                                                                |
| G11 | After a move      | The selection and the expanded Groups follow the moved item                                                                                                                                                                                                                                    |
| G12 | Heading           | The full path, `Python › Setup › macOS › Install`. When it does not fit, the middle Groups collapse to `…`, one at a time, keeping the Project and the Tutorial; the tooltip has the full path                                                                                                 |
| G13 | Keyboard          | Moving is mouse-only in this version                                                                                                                                                                                                                                                           |
| G14 | Version           | 0.3.0                                                                                                                                                                                                                                                                                          |

### Out of scope for v0.3.0

- Moving with the keyboard, or with a "Move to…" menu
- Dragging Projects, or dragging into the Projects folder's top level
- Custom order (still newest first; see ADR 0002)
- Undo, other than dragging back or the Trash
- Turning a Tutorial into a Group or the other way round

## 2. User flows

### Organising a Project

1. Hover **Python** → **+** → **New Group** → type "Setup" → Return. A `Setup` folder with a hidden `.tuto-group` file is created, and Python is expanded.
2. Hover **Setup** → **+** → **New Tutorial** → "Install" → Return. The Tutorial is created inside Setup and selected; the heading reads `Python › Setup › Install`.
3. Drag the existing Tutorial **Quick start** onto **Setup**. It moves inside; if Setup already had a "Quick start", the move is refused and the status line says why.

### Things made in Finder

- A folder with subfolders and no images shows as a Group, even without the hidden file.
- An empty folder shows as an empty Tutorial (with Start recording). To make an empty Group, use **New Group** in the app.
- A Tutorial that holds images stays a Tutorial even if a subfolder is added to it; the subfolder is ignored.

## 3. Architecture changes

### Paths instead of two names

A Tutorial is no longer `{ project, tutorial }` but a **path**: the folder names from the Project down, `['Python', 'Setup', 'Install']`. A Project is a path of length 1. Everything that named a Tutorial now takes a path: the selection, the image URLs, the IPC channels, the capture folder.

- **Keys:** a path joined with `/` (`Python/Setup/Install`). Folder names cannot contain `/`, so the key is unambiguous. The expanded list is stored as keys; v0.2's expanded Project names are already valid keys.
- **Selection migration:** a v0.2 `selectedTutorial: { project, tutorial }` reads as the path `[project, tutorial]`.
- **Safety:** each segment is checked the way names are today: it must be an existing, visible, non-link direct child of the previous one. A path never leaves the Projects folder.

### Main process

| Module                 | Change                                                                                                                                                                                                                                                                                                         |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `projects.ts`          | `classify(folder)` (G3); `listTree()` recursive, Groups first (G4); `createProject`, `createItem(parent, kind, name)`; `rename(path, to)`, `trash(path)`, `countTutorials(path)` (recursive), `move(path, destination)`; `tutorialPath`, `listImages`, `imagePath`, `trashImage`, `trashAllImages` take a path |
| `settings.ts`          | `selectedTutorial: string[] \| null`, `expanded: string[]` (keys); reads v0.2 files; `followMove(from, to)` (rename and move are both a path change) and `forget(path)` replace the four v0.2 follow/forget functions                                                                                          |
| `imageUrl.ts`          | Any number of path segments: `tuto-image://thumb/<seg>/…/<seg>/<file>?v=…` (at least a Project, a Tutorial and a file)                                                                                                                                                                                         |
| `tutorialRecording.ts` | Uses the selected path                                                                                                                                                                                                                                                                                         |
| `menu.ts`              | `showCreateActions` (the **+** menu: New Tutorial / New Group)                                                                                                                                                                                                                                                 |
| `ipc.ts`               | New and renamed channels (below)                                                                                                                                                                                                                                                                               |

### IPC contract changes

| Channel                                                                                                       | Change                                                                                                          |
| ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `projects:list`                                                                                               | Returns the recursive tree (`ProjectNode { name, children: TreeNode[] }`, `TreeNode { kind, name, children? }`) |
| `items:create`                                                                                                | New: `(parent: string[], kind: 'tutorial' \| 'group', name)` → `NameResult`                                     |
| `items:rename`                                                                                                | Replaces `projects:rename` and `tutorials:rename`: `(path, to)` → `NameResult`                                  |
| `items:trash`                                                                                                 | Replaces `projects:trash` and `tutorials:trash`: `(path)` → `boolean`                                           |
| `items:move`                                                                                                  | New: `(path, destination: string[])` → `NameResult`                                                             |
| `menu:create-actions`                                                                                         | New: `{ x, y }` → `'tutorial' \| 'group' \| null`                                                               |
| `tutorials:create`                                                                                            | Removed (now `items:create`)                                                                                    |
| `settings:select-tutorial`, `settings:set-expanded`, `tutorial:open-in-finder`, `images:list`, `images:trash` | Take a path (and keys for the expanded list) instead of `TutorialRef`                                           |

`projects:create` stays as it is.

### Renderer

- `sidebar/treeView.ts`: recursive rows with a `depth`; Group rows; the editing kinds become `{ kind: 'new', parent, what: 'project' | 'group' | 'tutorial' }` and `{ kind: 'rename', path }`; new pure `canDrop(source, target)`.
- `sidebar/sidebar.ts`: indentation per depth (set through the CSSOM, `element.style.setProperty`, which the CSP allows, unlike a `style` attribute); the **+** menu; HTML5 drag and drop with the highlight and the hover-to-expand timer.
- `tutorial-preview/previewView.ts`: `headingVariants(path)`, the full path then each shorter form; `preview.ts` or `main.ts` shows the first that fits.

## 5. Testing

**Unit (Vitest):** `classify` for every rule and their order; the recursive tree and its order; create Group writes the tag; rename, trash and count at depth; `move` (into another Project, into a Group, name taken, into itself or a descendant, onto a Tutorial, onto the current parent); settings migration from v0.2 and `followMove`/`forget` on selection and expanded keys; image URLs at depth 2 and 5; `buildSidebarRows` at depth; `canDrop`; `headingVariants`.

**Manual checklist (packaged app):**

- [ ] v0.2 data (Projects with Tutorials, a selection) opens unchanged
- [ ] New Group and New Tutorial from the **+** menu, at depth 1 and 3
- [ ] An empty new Group shows as a Group, not as a Tutorial
- [ ] A nested folder made in Finder shows as a Group; an empty one as a Tutorial; a Tutorial with images keeps its images after a subfolder is added
- [ ] Groups first, then Tutorials, newest first, at every level
- [ ] Rename and trash a Group; the confirmation counts its Tutorials; the selection follows a rename and clears on trash
- [ ] Drag a Tutorial into a Group, into another Project, and back; drag a Group with contents
- [ ] Refused: a name already used at the destination, a Group into itself or its own child, onto a Tutorial; a Project cannot be dragged
- [ ] Hovering a collapsed Group while dragging expands it
- [ ] Recording and the preview work for a Tutorial three Groups deep
- [ ] A long path shortens in the heading and the tooltip has it in full

## 6. Risks and mitigations

| Risk                                                                                             | Mitigation                                                                                                                     |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| Classifying every folder reads every folder on each 1.5 s poll                                   | One `readdir` per folder; Tutorial folders stop at the first image. Revisit with `fs.watch` if a large Projects folder is slow |
| A move across volumes (a Group that is a mount point) fails with `EXDEV`                         | Reported as the move's error; nothing is copied                                                                                |
| HTML5 drag and drop in Electron shows the OS drag image and may allow dropping files from Finder | The sidebar only accepts drags that it started (a private data type); everything else is ignored                               |
| Deep paths make the sidebar unreadable                                                           | 8 px indent per level (reduced from 16 px after trying it), names cut with `…` and the full name in the tooltip                |
| A Finder-made folder that is meant to be a Group but is empty shows as a Tutorial                | Documented; New Group in the app tags it                                                                                       |
