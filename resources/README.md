# Runtime resources (`resources`)

Images that the main process loads while the app runs. They are generated by `npm run icons` from the logo in [`build`](../build/README.md); do not edit them by hand.

| File           | Used for                                                                                                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `icon.png`     | The window icon on Windows and Linux (macOS takes the icon from the app bundle instead).                                                                                             |
| `icon-mac.png` | The Dock icon in dev mode (`npm run dev`), where macOS would otherwise show Electron's icon. It has the margin and shadow macOS icons use, so it looks like the packaged app's icon. |

Both are imported in [`src/main/index.ts`](../src/main/README.md) with Vite's `?asset` suffix.
